Task Test Cases & Verification Suite

Step-by-step test scenarios for verifying completed Phase 1 tasks

Phase 1 QA Ready
TC-1.1: Squad Creation, Edit, Delete & Detail Modal Squads
  1. Navigate to Clubs & Squads tab and type "Badminton" or "Riverside" in the search bar, or select a sport filter → Verify cards filter live.
  2. Click Create a Squad, fill in name, sport, max members, and venue, then submit → Verify the 2–3 char badge abbreviation is auto-generated from the squad name and the card displays equal-width Details and Edit Squad buttons plus a top-right trash icon.
  3. Click Edit Squad on the card (or inside SquadDetailModal) to update squad details, or click the top-right delete icon to confirm deletion via ConfirmDialog.
TC-1.2: Explore Event → Match Chat Integration Explore & Chat
  1. On Explore Games, click Details on any event card (e.g., Casual Pickup Basketball Run).
  2. In EventDetailModal, click Open Match Chat.
  3. Verify the app navigates directly to the Chat tab, automatically selects (or creates) that match's chat channel, displays the host's pinned announcement, and allows sending a new message.
TC-1.3: Interactive Sports Passport Editing Passport
  1. Navigate to Sports Passport and click Edit Bio under the player bio → Modify text and click Save Bio → Verify bio updates inline.
  2. Click + Add Sport, enter "Tennis" and role, and click Save Sport → Verify the new sport row appears; click the trash icon to test removing a sport.
  3. Click any day in Weekly Playing Availability (e.g., Mon) → Verify it cycles through Busy → Evening/Preferred → Available/Primary.
TC-1.4: Client Persistence & Full EN/VI Localization i18n & Storage
  1. Switch language between English and Tiếng Việt in the top bar → Verify CreateEventModal, SquadsSection, ChatSection, and PassportSection translate 100% of labels.
  2. Join an event, send a chat message, create a squad, or edit your passport, then refresh the browser (F5) → Verify all changes persist via localStorage.
TC-1.5: Host a Game Currency ($ / VND), Free Checkbox, Capacity (2–100) & Leading-Zero Fix review.md
  1. Click Host Game → Verify modal is widened (max-w-2xl) and Player Capacity (2–100) defaults to 10.
  2. Clear the Player Capacity field completely with Backspace → Verify the input becomes completely empty (no stuck 0 left behind). Try typing 001 or 012 → Verify leading zeros are stripped immediately (becomes 1 or 12), values > 100 clamp to 100, and values < 2 show an inline validation error and toast.
  3. Uncheck Free activity → Verify currency displays $ in English and VND in Vietnamese, and typing <= 0 is blocked.
TC-1.6: Host Status Badge, Pass Host Role & Confirm Dialog on Delete + Toasts review.md
  1. Create a new match via Host Game → Verify toast appears, the card shows a dark 👑 Host badge, and the button shows Delete Match. Click Delete Match → Verify ConfirmDialog opens asking for confirmation. Click Cancel (or press Escape) → Verify match is kept. Click Delete Match and confirm → Verify match is deleted with a toast.
  2. On an event where you are Host with registered teammates (e.g., Saturday Morning 5K & Coffee Social Run), try clicking Cancel / Leave Game Spot → Verify leaving is blocked with a warning toast instructing you to pass the Host role first.
  3. Inside EventDetailModal, click Pass Host next to a teammate in the roster → Verify toast confirms Host transfer, your badge switches from Host to Joined, and you can now leave the match.
